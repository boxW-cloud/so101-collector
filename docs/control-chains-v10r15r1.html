共用的采集旁路

主臂 action 在供数开关为 1 时镜像进入 Redis；Perceptor 将状态、图像引用写进 observation 队列。so101-collection 只负责开关、消费、配对、录制与 LeRobot 封装。放弃采集会关闭供数，不停止主从跟随。

七个原动作的限速和力矩限制保留。原动作执行时暂停跟随，结束后主臂 action 可再次覆盖最终姿态。跟随缺少新 action 超过 0.5 秒后保留最后目标。

当前姿态的实际限制

主臂肩部目标约 −103.78°、肘部约 96.92°，超出 Isaac 的 −100° / 90° 范围，仿真后端会裁剪。实际观测约 −99.78° / 89.23°。本轮链路连通不等于一比一到位或精度验收；action 保留主臂指令，可能与仿真实际下发值不同。

本轮现场批次仅验证原始帧与配对，使用放弃收尾，未封存或上传该批。原生 LeRobot 导出由隔离测试覆盖。若同时执行七个原动作，主臂 action 不一定是当时的实际控制指令，本轮未混用两种入口。
