# 版本与清理规则

1. 主目录只有当前版本，历史代码通过 Git 提交和版本 tag 查找，不再堆叠 `v10r*` 文件夹。
2. 当前稳定发布是 `v10r16`，镜像为 `so101-collection:20261105-v10r16`。组件身份见根目录 `release.json`；修改后创建新标签，不覆盖已验收标签。v15r1 及其文档保留。
3. 数据、配置和凭据由外部持久化目录保存，不随代码版本复制；不要把旧目录中的 `.env`、数据或密钥提交到公开仓库。
4. Spark 保留当前镜像、上一版 v10r15r1 回退镜像、构建所需基础镜像及正在使用的伴随组件。已保留的 v10r14 历史包未因本次更新删除。旧版镜像压缩包按需定向清理，数据目录不参与版本清理。
5. 已停止的旧容器，需核对挂载与可写层后再删除。删除容器时不删除 volume；禁止用全局 `docker system prune --volumes` 代替本项目定向清理。
6. v10r16 更新仅替换采集容器；Isaac、主臂、Perceptor 和其他平台服务不重启。GitHub 保存源码；镜像仍位于 Spark 的 Docker 本地存储。

仓库保留第三方来源和原有许可证文件，不为第三方代码重新声明许可。
